# Email service provider (ESP) click-, open- and redirect-tracking domains.
#
# Links on these hosts are redirectors by design: following one is expected to
# land on another domain, and an open-tracking pixel is not a page worth
# opening. What being listed here does, and does not, buy a link:
#
# * No "long tracking code" signal (url.opaque_token_unknown_host).
# * Hopping from one of these to the real destination is not a suspicious
#   redirect, and a link whose text names the sender's own site but whose href
#   goes through one of these is not a "text does not match" trick.
# * It does NOT make the destination trusted: the link is still opened in the
#   sandbox and the page it lands on is judged on its own.
#
# Brands also run click tracking on their own subdomains (click.e.example.com,
# links.example.com, email.example.com, mkt.example.com). Those need no entry:
# analysis/trust.py treats every host under the sender's own Google-verified
# domain as the sender's, so "click.attacker.example" earns nothing unless the
# mail really came from attacker.example (and then it only reaches itself).
#
